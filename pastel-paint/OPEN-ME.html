🚀 Start Pastel Paint Server

To use all features (fill tool, undo/redo, save), you need to run a local server.

Step 1: Open PowerShell

Press Windows Key + X, then click "Windows PowerShell" or "Terminal"

Step 2: Navigate to the folder

Type this command and press Enter:

cd "C:\Work\mishika-projects\snake-game-2\pastel-paint"

Step 3: Start the server

Type this command and press Enter:

python -m http.server 8000

Step 4: Open in browser

Once you see "Serving HTTP on 0.0.0.0 port 8000", click the button below:

Open Pastel Paint 🎨

💡 Tip: Keep the PowerShell window open while using the app!
