# 🎮 Games Arena ✨

Welcome to the **Games Arena**, a collection of beautiful, child-friendly games designed with a soothing pastel aesthetic and premium feel.

## 🚀 Live Demo
You can view the main arena lobby at `index.html`.

## 🐍 1. Pastel Snake Game
A refined version of the classic Snake game, built for fun and accessibility.

### ✨ Key Features
- **Lives System**: Start with 3 lives (❤️). Each collision costs a life, but preserves your score!
- **Global Leaderboard**: Tracks the top 10 scores with persistent username storage. 🏆
- **Audio Feedback**: Generative "Pop", "Uh-oh", and "Oh no" sounds for a playful experience. 🔊
- **Instruction Cloud**: A floating ☁️ that guides you on how to pause.
- **Start Instruction Heart**: The game waits for your first move, showing a beautiful pulsing heart ❤️ instruction.
- **Premium Design**: Linear gradients, floating animations, and a soft lavender grid.

---

## 🧩 2. Memory Match
A peaceful emoji-based matching game to test your memory skills.

### ✨ Key Features
- **Pastel Palette**: Soft colors and friendly interface.
- **Difficulty Balance**: Optimized card grid for focused play.
- **Win State**: Celebratory "You Did It!" overlay with move counting.

---

## 🛠️ Built With
- **Vanilla JavaScript**: Pure logic without heavy frameworks.
- **HTML5 Canvas**: Smooth rendering for the Snake engine.
- **Web Audio API**: Real-time generative sound effects.
- **CSS3 Animations**: Premium transitions and UI effects.
